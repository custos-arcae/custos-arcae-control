# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the
`custos-arcae-control` repository and the wider `custos-arcae` organisation.

Format and conventions are defined in [ADR-0001](0001-record-architecture-decisions.md).

## Index

| ADR | Title | Status | Date | Review due |
| --- | --- | --- | --- | --- |
| [0001](0001-record-architecture-decisions.md) | Record architecture decisions | Accepted | 2026-11-24 | 2027-11-24 |
| [0003](0003-site-identity-and-naming.md) | Site identity, host naming, and inventory directory convention | Proposed | 2026-11-26 | 2027-11-26 |

## Status values

- **Proposed** — under discussion; not yet authoritative.
- **Accepted** — approved by deciders; implementation may begin.
- **Deprecated** — no longer applies; kept for historical record.
- **Superseded by ADR-NNNN** — replaced by a later decision.

## Conventions

- Numbers are zero-padded to four digits and never reused.
- An accepted ADR is never edited except to change its `Status` line.
- Deciders are roles/teams, never natural-person names (GDPR Art. 5(1)(c)).
- Every ADR carries a review date no more than 12 months after acceptance.
